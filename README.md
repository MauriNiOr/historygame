# 🥷 Ninja Escape Arena

Juego 2D de **Escape Room + Combate** con perspectiva top-down.

## Características

- Menú de inicio + selección de niveles (1 al 5)
- Combate con espada de energía
- Recolecta llaves para abrir la puerta de salida
- Enemigos: Slimes, Guerreros y Boss final
- Sprites del personaje incluidos (`player_sprites.jpg`)

## Controles

| Tecla | Acción |
|-------|--------|
| **W A S D** o **Flechas** | Mover |
| **Espacio** | Atacar |
| **E** | Interactuar (abrir puerta) |

## Cómo jugar

1. Abre `index.html` en un navegador.
2. Pulsa **JUGAR** o elige un nivel.
3. Derrota a los enemigos, recoge las 🔑 llaves y abre la puerta 🔒 para escapar.
